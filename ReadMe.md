#### Description
This repo holds the hads on practice programs from the book "Go for Dummies"

##### Compilation
<p>
    To compile the code: use go build __the program name__ without underscores
    run: .\program name

    If you have multiple files then create a module file:
    go mod init __module_name__
    then: go build __specify_module_name__ give a module name say mymodule
    run: .\mymodule.exe

    specify the build name: go build -o mymodule.exe
</p>
